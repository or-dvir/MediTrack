# MediTrack Project Rules

## Mockup style

Before creating or editing any visual mockup or design asset in `docs/design`, read [`docs/design/style.md`](docs/design/style.md) in full and follow it.

Treat that file as the single source of truth for mockup tokens, component styling, and presentation. Do not duplicate its rules here; it may change. If a mockup needs a token or component not defined there, ask Or before changing the style file or introducing it.
